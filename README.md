# Agro Forte: O Futuro Sustentável

## Descrição
O projeto **Agro Forte** é uma plataforma educacional e informativa que explora o futuro da **agricultura sustentável** no Brasil. Com foco em práticas inovadoras e ecológicas, o site oferece uma visão sobre como o **setor agropecuário** pode contribuir para um futuro mais sustentável.

## Funcionalidades

- **Modo Claro/Modo Escuro**: Alternância entre modos para uma melhor experiência de leitura. O tema é salvo usando **localStorage** e persistente entre sessões.
- **Vídeos Educacionais**: Seção com vídeos explicativos sobre o impacto e as inovações no setor agropecuário sustentável.
- **Links Úteis**: Lista de links externos relacionados a políticas agrícolas, sustentabilidade e organizações relevantes.
- **Design Responsivo**: O layout é completamente responsivo, ajustando-se perfeitamente a qualquer tamanho de tela.
- **Interatividade**: Efeitos dinâmicos, como animações e rolagem suave, melhorando a experiência do usuário.

## Tecnologias Usadas

- **HTML5**: Estrutura semântica e acessível.
- **CSS3**: Estilos avançados com variáveis, animações e design responsivo.
- **JavaScript**: Manipulação dinâmica do DOM, alternância de tema, e interatividade.
- **localStorage**: Armazenamento local para preferências de tema.

## Como Rodar o Projeto

1. **Clone o repositório**:
    ```bash
    git clone https://github.com/seu-usuario/agro-forte.git
    ```

2. **Abra o projeto no seu navegador**:
   - Basta abrir o arquivo `index.html` no seu navegador para visualizar o site.

3. **Testando a Alternância de Tema**:
   - Clique no botão de alternância de tema (no canto superior direito) para alternar entre o modo claro e escuro.
   - A preferência será salva em seu navegador para futuras visitas.
