# Agro Forte: O Futuro Sustentável

## Descrição
O projeto **Agro Forte** visa apresentar como o setor agropecuário do Brasil está cada vez mais alinhado com práticas sustentáveis. Através de uma plataforma visualmente atraente e interativa, o site oferece conteúdo educativo sobre o futuro da agricultura no país, com ênfase em práticas ambientais responsáveis, inovação tecnológica e sustentabilidade.

## Funcionalidades

- **Modo Claro/Modo Escuro**: Alternância entre temas para oferecer uma experiência personalizada para o usuário. A preferência de tema é armazenada para futuras visitas.
- **Vídeos Educacionais**: Seção de vídeos com conteúdo relevante para o setor agropecuário sustentável.
- **Links Úteis**: Links para sites relacionados a políticas agrícolas, sustentabilidade e inovação.
- **Design Responsivo**: Totalmente adaptável a dispositivos móveis e desktops.
- **Interatividade**: Animações suaves, transições e scroll suave para links internos.

## Tecnologias Usadas

- **HTML5**: Estrutura semântica e responsiva.
- **CSS3**: Estilos avançados, com variáveis, transições e design responsivo.
- **JavaScript**: Interatividade e manipulação do DOM, com animações e controle de preferências (modo claro/escuro).
- **LocalStorage**: Armazenamento das preferências de tema do usuário.

## Como Rodar o Projeto

1. **Clone o repositório**:
    ```bash
    git clone https://github.com/seu-usuario/agro-forte.git
    ```

2. **Abra o projeto no seu navegador**:
   - Basta abrir o arquivo `index.html` no seu navegador para visualizar o site.

3. **Testando a Alternância de Tema**:
   - Clique no botão de alternância de tema (no canto superior direito) para alternar entre o modo claro e escuro.
   - O tema será salvo em seu navegador para futuras visitas.
